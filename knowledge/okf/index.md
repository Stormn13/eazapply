# Career Knowledge Base Index

This directory is the canonical source of truth for personal career knowledge.

## Purpose

This OKF knowledge base is intended to store structured, individually retrievable
career records that can later be used by the resume-generation pipeline.

## Record types

- Profile
- Education
- Skills
- Projects
- Experience
- Achievements
- Certifications
- Activities

## Storage model

Each record is intentionally kept as a separate Markdown document or directory so
that it can later be queried independently.

## Notes

- No personal information is included yet.
- No fabricated facts or claims are included.
- This is a schema/template foundation only.
